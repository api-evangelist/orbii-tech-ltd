# Orbii Tech Ltd

> Orbii is a MENA-region credit and lending infrastructure company. Its API turns raw business financial data (bank transactions, invoices) into automated underwriting signals: KPIs, risk assessment, band classification, and suggested loan amounts. Fintech lenders, neobanks, and merchant platforms use it to launch and scale SME lending. Backed by Prosus, VentureSouq, Dash Ventures, and Sanabil 500.

## APIs
- [Orbii API (main)](https://api.docs.orbii.ai/): Transactions, clients, companies, KPIs, risk assessment, band classification, invoice-based lending. Base https://api.orbii.ai
- [Orbii KSA API](https://api.docs.orbii.ai/ksa): Saudi Arabia regional deployment. Base https://api.sa.orbii.ai
- [Orbii OMN API](https://api.docs.orbii.ai/): Oman regional deployment. Base https://api.om.orbii.ai
- [Orbii API - Foodics](https://api.docs.orbii.ai/): Foodics POS partner deployment (micro-loan KPIs/scoring). Base https://api.foodics.orbii.ai
- [Orbii API - Rewaa](https://api.docs.orbii.ai/): Rewaa retail partner deployment (eligibility, risk, band, loan amounts). Base https://api.rewaa.orbii.ai
